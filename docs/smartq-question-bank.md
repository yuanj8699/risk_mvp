# 小 Q 追问自动改写知识库与补充问句清单

> 用途：当用户在工作台追问**字典外临时指标、监管红线筛查或细粒度下钻问题**时，后端自动将相关监管底线、业务参考预警线与标准单项指标问句注入 Pi Agent 上下文，由 Agent **自主判断**是否需要补查及如何改写为规范的小 Q 问句。
> 原则：面向全体 82 家行社（同时兼容按地区/单行社下钻）；**严格区分法定监管底线与行业/项目参考预警线**；若用户在追问中自行指定阈值（如“不良率＞2%”），始终优先尊重用户指定的阈值。

## 三、Agent 自主判断机制说明

1. **先查归档**：Pi Agent 收到追问后，必须先调用 `read_task_evidence` 检索当次扫描归档；归档已有充分证据时直接回答，不触发小 Q。
2. **自主改写与选阈值**：当归档缺少该指标（如字典外指标：低评级债券、久期、涉农占比、票贷比、异地贷款、流动性比例、大客户集中度等）或用户问开放式筛查问题（如“哪些行社不良率偏高？”“有没有资本充足率不达标的行社？”）时，Pi 自主参考注入的 `domain_guidance` 选择监管底线或参考预警线，改写为无歧义中文问句并说明选用依据（`reason`）。
3. **宿主安全执行与范围隔离**：改写后的问句交回 Python 宿主执行 `SmartQStreamClient.query`（AK/SK 绝不传给 Node/Pi）。单行社视角下强制校验防越权查询与行级过滤，返回结果标注为「小 Q 实时补查 · 口径仅供参考」。
